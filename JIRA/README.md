# Fluxo de QA com JIRA — Tickets, Bugs e Scrum Board

Repositório de estudos práticos com JIRA focado no fluxo de trabalho de equipes de **Quality Assurance** em ambiente ágil.

O objetivo é documentar como o JIRA é usado por analistas de QA para gerenciar testes, registrar bugs e acompanhar o ciclo de vida de defeitos dentro de um time de desenvolvimento.

## Ferramentas utilizadas

- JIRA (Atlassian) — gestão de projetos e rastreamento de bugs
- Metodologia Scrum / Kanban
- Conceitos: Smoke Test, Reteste, Teste de Regressão
