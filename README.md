## 📋 Casos de Teste

Casos de teste escritos com estrutura completa:
**pré-condição → passos → resultado esperado → status**

| Suite | Cenários | Cobertura |
|---|---|---|
| Login / Autenticação | 10 casos | Fluxo feliz, negativos, edge cases, segurança |

**Técnicas aplicadas:**
- Partição de equivalência
- Análise de valor limite
- Tabela de decisão
- Fluxo alternativo e de exceção

---

## 🐛 Bug Reports

Bug reports estruturados com:
- Título objetivo e rastreável
- Passos para reprodução
- Resultado obtido vs. resultado esperado
- Severidade (Crítica / Alta / Média / Baixa)
- Evidências (prints/logs)

---

## 🗄️ SQL

Consultas SQL utilizadas para **validação de dados em banco**, uma habilidade essencial para QA:

- Validação de registros criados via API
- Verificação de integridade referencial
- Consultas para suporte a bug reports
- Queries de auditoria e rastreabilidade

---

## 📌 JIRA

Exemplos práticos de uso do Jira em contexto de QA:

- Criação e rastreamento de bugs
- Vinculação de casos de teste a histórias de usuário
- Workflow de issues: `Aberto → Em andamento → Em teste → Fechado`
