# SQL para QA — Validação e Análise de Dados em Testes

Repositório de estudos práticos de SQL com foco na aplicação em **Qualidade de Software (QA)**.

O objetivo é documentar como queries SQL são usadas por analistas de QA para validar dados, investigar bugs e verificar regras de negócio diretamente no banco de dados — indo além da interface da aplicação.
